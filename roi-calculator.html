About the ROI Calculator

Calculate return on investment and annualized return from cost and final value. ROI = (final value - amount invested) / amount invested x 100. Annualized return = (final / invested)^(1/years) - 1. Results are estimates and may differ from official or bank figures.

How to use

  1. Enter your values or choose a file.
  2. Press Calculate.
  3. Copy, print or share the result.

Frequently asked questions

How is the roi calculator calculated?

ROI = (final value - amount invested) / amount invested x 100. Annualized return = (final / invested)^(1/years) - 1.

Is the result exact?
